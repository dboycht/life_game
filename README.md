# 生命游戏 (life_game)

## 介绍
康威生命游戏(Game of Life)，剑桥大学约翰·何顿·康威设计的计算机程序。
我用python编写了复刻版本。

v1.3 起为「引擎 / 界面」分层结构，仅用 Python 标准库，零第三方依赖：
- `engine.py` 环面棋盘引擎（标准 B3/S23 规则，整代同步更新）
- `patterns.py` 预设图案库（滑翔机、LWSS、脉冲星、R-五连块、高斯帕滑翔机枪）
- `gui.py` tkinter 图形界面；`cli.py` 终端界面；`version.py` 版本号单一来源

## 运行
需要 Python 3（仅标准库，无需安装任何包）。

| 形态 | 命令 |
| --- | --- |
| 图形界面 | `python3 main.py` |
| 终端界面 | `python3 cli.py` |
| 引擎自测 | `python3 selftest.py` |

## 界面说明（GUI）
- 开始/暂停、单步、清空、随机（数量精确、坐标不重叠）
- 预设图案：选中后「放置」在棋盘中央，可多次放置
- 速度滑块 10~500ms，也可在输入框直接键入 1~10000ms（回车或失焦生效），与滑块双向同步；横纵尺寸输入后「应用尺寸」（横 5~160，纵 5~100），窗口随棋盘自适应，打开即整幅可见
- 鼠标左键画活细胞，右键擦除
- 棋盘为环面：细胞出界绕回对侧
- 「关于」按钮查看版本、规则与作者信息

## 验收
`python3 selftest.py` 输出 `11/11 通过` 且退出码为 0，即引擎规则
（静止物 / 闪变 / 滑翔机 / 飞船 / 脉冲星 / 滑翔机枪 / 环面 / 随机不重叠）全部通过。
